# Boundary — Tracera

Tracera owns persistent product identity and accepted intent, the canonical product graph, trace/evidence interpretation, dissatisfaction detection and product/stage assessment. Human and machine navigation, history and integrations support that boundary.

AgilePlus retains work/execution authority. Git/source repositories retain source authority. Verifiers retain measurement provenance. Tracera references these facts without becoming a competing work scheduler, Git store or generic agent runtime.

Product scope is not defined by the number of generated FRs, the current deployment topology, or every incidental crate present. Mature scope, stage applicability and auxiliary work require semantic review. Early viable stages must close real journeys behind mature-shaped boundaries; temporary adapters require bounded transition debt.

The fixed generated TRC-MATURE-V1 and its positional stage assignments are invalidated. This correction does not retire existing product obligations. See [the controlling method](../governance/atlas/COUNT-INDEPENDENT-SPECIFICATION.md).
