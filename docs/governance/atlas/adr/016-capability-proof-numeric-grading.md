# ADR-016 — Capability-first composition and evidence-bound numerical grades

Status: Proposed; elaborates INT-006. No approval or engine receipt is manufactured.

Context: UI embedding was too prominent in the prior federation narrative; visible features could be accepted from logs, designs remained transient, and rejection of naive averages obscured the user's legitimate need for an actual grade.

Decision proposal: compose capabilities at appropriate layers, require canonical design plus independent user-path/pixel proof where applicable, and publish a fixed-rubric numerical score with noncompensatory mandatory gates. Preserve role/profile differences, missing evidence, scope evolution, and original source authority.

Rejected alternatives: embedded-app launcher as the product; one transport everywhere; log-only graphical verification; one global screenshot score; unversioned weights and arbitrary completion percentages; only qualitative traffic lights; universal line-by-line narrative; copy/fork every shared capability; whole-platform completion before useful product slices.

Consequences: additional adapter and evidence work; lower repeated integration cost; explicit residual uncertainty; stronger release refusal on unproven critical behavior. Revisit profile weights and evidence policies through real calibration, user feedback and qualified native results, not through pressure to improve the displayed number.
