# Capability composition, observable products, canonical design and machine grading

**Version 1.4 / September 16, 2026.** This amendment turns the latest human clarification into proposed executable contracts. It is not a fresh portfolio audit, an operational bridge, a newly approved roadmap or an assessed product grade. One existing owner chat per current non-zz repository remains the inherited allocation; refresh identity and active leases rather than silently preserving a historical count.

## Read in order

1. [Capability composition](CAPABILITY-COMPOSITION.md): federation without any embedded peer UI.
2. [Bridge and action contract](AGENT-BRIDGE.md): actual state, pixels, user input and diagnostics.
3. [Visual verification](VISUAL-VERIFICATION.md): fine spatial/temporal features and known-bad controls.
4. [Canonical design state](DESIGN-STATE.md): inspectable mockups, variants, fixtures and approvals.
5. [Artifact and traceability model](TRACEABILITY.md): intent through installation, with reverse checks.
6. [Numerical grading](GRADING.md): frozen denominators, category weights, real evidence and critical gates.
7. [Owner matrix](OWNER-MATRIX.md), [work plan](WORK-PLAN.md) and [all-agent addendum](../prompts/CAPABILITY-PROOF-GRADING-ADDENDUM.md).

The reference grader computes a score from structured supplied evidence. It validates identity, freshness and local payload hashes but cannot authenticate producers, judge pixels or prove approval. Its output always marks those limits. Synthetic fixtures are not product results. Native bridge adapters, calibration studies, graphical captures, new mockups and product grading remain work to execute.

## Precedence

This amendment makes capability/behavior composition the primary federation model; embedded UI remains optional. It explicitly permits defensible numerical grades and percentages. Historical statements rejecting all aggregate scores are superseded only to that extent. Critical gates, independent assurance floors, source truth, permissions and no-fabrication rules remain intact. SROC/CDP retain their unresolved definitions; this does not redefine either acronym or create another canonical scorecard product.
