# Federation acceptance scenarios

These are planned tests, not a passing report. Execute real supported standalone/composed profiles, both declared host directions, and role-appropriate platform paths. Record source, recipe, package, policy, grant and provider-instance identities. Reject fixture-only results for product graduation.
