## Product topology rule
Default target:
- one GUI-native desktop/workbench product (HeliosLab role);
- one canonical coding CLI unless a second client/runtime role survives evidence;
- one shared generic agent framework/harness responsibility;
- multiple adapters/protocols/packages are allowed without multiplying agent cores.

Two CLIs require a stable job/user/runtime boundary plus measured value exceeding maintenance/convergence cost.
