# MACE/autograder doctrine — assignment-defined control loop

Date: 2026-09-29. MACE here denotes the loop specified by the user, not an independently verified attribution to a particular external paper/framework. External acronym attribution remains unresolved and is not needed to apply the accepted assignment.

Accepted contract -> bounded context -> worker action -> independent grader -> multidimensional result -> localized feedback -> minimal next context -> retry/replan/clarify/escalate.

The worker may read the rubric. Protection comes from authority and evidence boundaries, not primarily secret tests. Policy changes require separate authorization; version/hash alone does not prove authority. Retain raw receipts and the relationship between assignment, attempt, candidate, grader and result. A historical work completion, agent assertion, mock UI or passing build is not product acceptance.

Keep three lifetimes separate: ephemeral worker/model/tool/sandbox/lease; durable development effort with change intent, work packages, dependencies/reviews and execution receipts; durable accepted product state with identities, configurations, artifacts/releases and qualified observations. A session ID is not automatically all three.

Evidence binds exact product/subject, contract/criterion, source/dependency/build/runtime candidate, configuration, environment, verifier/version/policy, run, timestamp and raw artifact provenance. KCode specifically needs serving daemon identity, not only the fresh client. Preserve statuses for not-run/skipped/collector-error/wrong-scope/stale/conflict. Empty criteria or failed collection cannot enter a pass numerator.

Trace both directions through intent/design/implementation/test/evidence/runtime, distinguishing accepted intent, authorized decision, deterministic source fact, verified observation, imported assertion, inference and superseded history. Confidence is not authority. A 99% inferred relation stays an inference.

Progress vectors preserve functional qualification, traceability, valid evidence, journey closure, regression, performance, reliability, security, accessibility, usability, uncertainty and transition debt. Critical failures cannot be averaged away. Scope delta is distinct from engineering delta. No percentage without a resolved denominator; no trend/asymptote without adequate comparable observations.

Adversarial controls are first-class now: positive/negative, stale/wrong-scope/missing/conflicting evidence, invalid input, authorization/dependency failure, timeout/cancel, restart, worker replacement, regressions, empty checks, verifier failure and implementation weakening its own grader. Removing a guard should create a witness detected by a protected check. Held-out tasks can complement this; they cannot repair an invalid evidence model.

This is doctrine and design. The local diagnostic scripts do not implement trusted attestation, immutable stores, native product recovery or a production grader. Their passing assertions never close the product gates.
