# Non-code completion gate — harness family

A non-code layer may be marked complete only when every applicable row is CLOSED with evidence.

## Archaeology
- alias/lineage map complete to reasonable falsification standard;
- bound conversations/prompts recovered or explicitly unavailable;
- Git history/predecessors/related repos classified;
- user intent separated from assistant suggestions and implementation accidents;
- contradictions resolved or escalated.

## Source denominator
- every meaningful source family inventoried;
- each row semantically resolved, not merely opened;
- mounted/reachable surfaces distinguished from stubs/reference/vendor code;
- current vs historical vs proposal/superseded classifications explicit.

## External research
- current Codex/jcode exact baselines frozen;
- generic harness SOTA research complete across research + production + adjacent distributed/workflow systems;
- papers have task/dataset/baseline/metric/limitations;
- competitor marketing claims qualified;
- bootstrap decision ledger complete.

## Existence/topology
- realistic alternative stacks constructed;
- capability lineage matrix complete;
- commodity/candidate/falsified/unverified differentiation ledger complete;
- segmented vs converged topology hypotheses attacked;
- HeliosLite sunset donor disposition complete;
- no repository survives because capability ancestry was mistaken for product identity.

## Mature semantic contract
- ontology reviewed against falsification workloads;
- mature product roles and boundaries explicit;
- functional obligations semantically decomposed with no target count;
- quality overlays separate;
- stage projections derived from mature contract;
- transition debt explicit.

## Journeys
- human and machine actor journeys complete;
- CLI/TUI/GUI/API/SDK/headless differences modeled as projections/clients;
- stage-required journeys identified;
- interruption/recovery/approval/failure journeys included.

## Architecture
- kernel/provider/tool/context/environment/durable-effort/scheduler/policy/evidence/event/control-plane/client boundaries decided or explicitly deferred to experiment;
- Agentora/PhenoShared absorption audit complete;
- custom-vs-bootstrap rationale for each major subsystem;
- high-risk architecture unknowns have experiment contracts even when execution remains pending.

## Trace/evidence
- intent ↔ design ↔ implementation ↔ tests ↔ evidence ↔ runtime schema complete;
- authority/provenance types explicit;
- evidence identity complete;
- orphan/contradiction/staleness rules defined;
- implementation mapping marks unmounted/stub/vendor/reference accurately.

## Oracle/test design
- positive/negative/wrong-scope/stale/conflict/missing/invalid/dependency/restart/auth/regression/replacement cases designed where applicable;
- false-green mutation reasoning performed;
- grader custody/version policy complete;
- held-out/adversarial strategy defined.

## Operations/supply chain
- release/runtime identity contract;
- compatibility/versioning/deprecation policy;
- secrets/IAM/approval boundary;
- observability/replay/retention policy;
- performance/resource/QoS measurement plan;
- migration/rollback/recovery contracts.

## Independent review
- fresh reviewer attempts to produce unexplained behavior/lifecycle/failure/configuration/journey/architecture;
- all blocking findings closed or explicitly implementation-experiment blocked;
- Registry and repo-local truth agree;
- no generated/invalid catalog participates in grading.

“Non-code complete” does not mean product complete. Any required runtime/implementation experiment remains an explicit blocker in the overall completion gate.
