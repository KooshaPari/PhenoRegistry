## Open research bodies beyond direct competitors

Durable workflow replay and effect idempotency; event sourcing and transactional outbox; capability security and OS sandboxing; process-tree supervision; protocol conformance; software supply-chain attestations; migration/recovery testing; property/mutation testing; terminal accessibility; reproducible resource benchmarking; human-in-the-loop approvals; general SDK composition and exit costs. These are research queues, not claims that a particular library already satisfies our requirements.

## Architecture freeze gate

For each significant custom subsystem, record use-directly/integrate/fork/adapt/compose/learn/reject/build-custom alternatives, exact version/license/project health, API/data model, recovery and failure semantics, supported deployment/platforms, integration burden and a discriminating experiment. No custom generic SDK, persistence engine, protocol or grader platform is approved merely by this pass.
