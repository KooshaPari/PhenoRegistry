3. **`kooshapari-repo-disposition-register.yaml`** — machine-readable portfolio register for local agents.

8. **`repo-boundary-rfc-template.yaml`** — mandatory gate for creating a new repository.
9. **`first-execution-queue.yaml`** — first 26 atomic portfolio tasks with dependencies and acceptance gates.
10. **`portfolio-before-transition-after-map.md`** — compact map for briefing or prompt injection.
