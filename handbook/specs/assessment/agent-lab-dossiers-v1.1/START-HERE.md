# Agent entrypoint — a filled dossier, not another planning layer

Read `README.md`, then `MASTER-ASSESSMENT-KIT.md`. Review one executed restoration dossier and one illustrative dossier so you understand why a stated outcome is not automatically admissible evidence.

1. Resolve the real subject, existing audit owner, authorized worktree, mandate, current accepted context, and latest checkpoint. Do not use a fictional example as authority.
2. Reuse the accepted audit path and stable schema contracts. Select a bounded beneficiary slice, profile, and target stage. Derive local intent when authorized; do not demand a human-authored repo idea.
3. Create or amend an assignment capsule. Inventory observations, claims, assumptions, missing requirements, and opportunities separately. Resolve applicability before acceptance; omit neither unknown obligations nor inconvenient failures.
4. Bind criteria to actual instruments and qualify valid/invalid witnesses. Use deterministic tools first, semantic review with evidence and countercases where needed, and actual consumers for outcome validation.
5. Produce canonical JSON results and evidence references at the exact subject snapshot. Keep source identity, assignment identity, report commit and registry receipt separate. Record absent identities as absent, not fabricated hashes.
6. Evaluate maturity by slice and independent axes. A gate is not passed by averaging irrelevant positives. Unknown, blocked, stale, contested and waived are not passes.
7. Fill context, inventory, findings, decisions, semantic contrary cases, and the restart packet in the dossier. Append/supersede accepted records; do not rewrite historical evidence.
8. Generate Markdown, HTML, normalized JSON, YAML, and JSONL views. Run both the core bundle checks and the dossier consistency checks. Read the human report; a renderer can have defects too.
9. Perform only genuinely authorized next actions. Queue registry integration rather than faking receipts or stopping unrelated work. Preserve failed hypotheses, actual permissions, remaining cumulative budget, and the next discriminating action for a fresh session.

**Required return:** the completed dossier path and exact subject/epoch, actual evidence gathered, explicit limits, slice-specific maturity, top findings with ownership, next action and countercase, and restart packet. Do not return only a new template or rubric.

Existing operational roles and permission boundaries are unchanged. The original full agent-lab protocol is in `core-v1.0/START-HERE-AGENT.md` and `core-v1.0/docs/00-SPECIFICATION.md`.
