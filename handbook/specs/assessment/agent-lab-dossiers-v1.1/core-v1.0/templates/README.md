# Templates

Templates are intentionally unaccepted and contain REPLACE_WITH values. Syntax validity never grants authority or qualifies evidence.

Use JSON as the portable authoritative representation. Markdown reports and checkpoints are views. Native schemas are in `schemas/`; additional cross-record checks are implemented by `tools/pep.py`. Do not copy template timestamps, zero digests or example identities into an operational record. These placeholders are rejected by operational record validation.
