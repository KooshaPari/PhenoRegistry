# D10 — Accessibility and internationalization

Status: authored candidate predicates. No product results or automatically qualified adapters are implied. Exact-duplicate checks do not establish semantic uniqueness; resolve cross-cutting overlaps when weighting an assignment.

## D10-P01 — Keyboard and focus access
Applicability trigger: keyboard-operable human interfaces.
Method: **DYNAMIC**. Traverse the actual interface without a pointer using the selected accessibility target; inspect focus, activation and escape behavior.

- **PEP-10-01-01** — All required interactive controls are reachable by keyboard.
- **PEP-10-01-02** — Keyboard focus remains visibly identifiable.
- **PEP-10-01-03** — Focus order follows the intended task sequence.
- **PEP-10-01-04** — Opening a modal places focus in the intended context.
- **PEP-10-01-05** — Closing a modal returns focus to a meaningful location.
- **PEP-10-01-06** — The user can escape a nonessential keyboard trap.
- **PEP-10-01-07** — Keyboard shortcuts do not unexpectedly override essential input behavior.
- **PEP-10-01-08** — Offscreen or hidden controls do not capture focus inappropriately.
- **PEP-10-01-09** — Re-rendering does not lose focus during a required task.
- **PEP-10-01-10** — A skip mechanism bypasses repeated navigation where the selected target requires it.

- **PEP-10-06-09** — A component pass is not generalized to an untested composed screen.
