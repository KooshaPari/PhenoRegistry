# D07 — Developer experience

Status: authored candidate predicates. No product results or automatically qualified adapters are implied. Exact-duplicate checks do not establish semantic uniqueness; resolve cross-cutting overlaps when weighting an assignment.

## D07-P01 — Clean checkout and setup
Applicability trigger: source-bearing products.
Method: **DYNAMIC**. Start from a clean authorized checkout on the supported platform; execute the documented setup without developer caches or undeclared credentials.

- **PEP-07-01-01** — A clean checkout identifies the minimum required tools.
- **PEP-07-01-02** — Setup does not depend on an undocumented local path.
- **PEP-07-01-03** — Required dependency installation completes under the declared environment.
- **PEP-07-01-04** — Setup detects an unsupported platform before destructive changes.
- **PEP-07-01-05** — Missing credentials produce a scoped actionable blocker.
- **PEP-07-01-06** — Development setup avoids modifying unrelated user configuration.
- **PEP-07-01-07** — A repeat setup is idempotent or clearly reports existing state.
- **PEP-07-01-08** — The first useful verification command is discoverable from the entry documentation.
- **PEP-07-01-09** — Uninstalling setup-owned resources leaves unrelated resources intact.
- **PEP-07-01-10** — The setup duration is measured under a declared cache condition.

Activation: use `templates/measurement-binding.template.json`. A catalog method is not a qualified instrument or a result.

Method: **DYNAMIC**. Measure edit-to-feedback for representative changes and deliberately introduce known syntax, type and behavior failures.

- **PEP-07-02-01** — A small source edit can trigger a relevant verification path.
- **PEP-07-02-02** — Known syntax errors are reported at the responsible source location.
- **PEP-07-02-03** — Type errors are distinguishable from dependency-resolution failures.
- **PEP-07-02-04** — A targeted test can be run without executing unrelated expensive suites.
- **PEP-07-02-05** — Incremental builds actually reuse eligible prior work.

- **PEP-07-02-09** — The inner loop has measured wall-clock latency for a representative change.
- **PEP-07-02-10** — Shared-machine contention is included when it is part of the development contract.

- **PEP-07-05-01** — A contributor can identify the accepted target branch and baseline.
