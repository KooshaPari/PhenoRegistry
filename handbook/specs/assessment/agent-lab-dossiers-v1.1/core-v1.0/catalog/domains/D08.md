Applicability trigger: products consumed by agents.
Method: **DYNAMIC**. Use an unprimed authorized agent or scripted consumer to discover operations and parse outcomes; perturb arguments and schemas.

- **PEP-08-01-01** — Available operations are discoverable through a documented machine-facing surface.
- **PEP-08-01-02** — Machine-readable success outputs conform to a stable schema.
- **PEP-08-01-03** — Machine-readable failures distinguish actionable error categories.
- **PEP-08-01-04** — Human decoration does not corrupt structured output streams.
- **PEP-08-01-05** — Help output describes required arguments and side effects.

- **PEP-08-01-07** — Interface versions can be determined before invoking risky operations.

- **PEP-08-01-09** — A successful empty result is distinguishable from a failed query.
