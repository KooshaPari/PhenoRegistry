# Product Evaluation Protocol — preliminary v0.1

Read `PRODUCT-EVALUATION-PROTOCOL-v0.1.md` first.

- `protocol.contract.json`: machine-readable design contract, **not JSON Schema or an executable validator**.
- `criterion-examples.json`: three illustrative criterion designs; **not qualified adapters or actual assessment results**.

This handoff is a proposed protocol. It is not the reconciled historical catalog, a working grading engine, an approved authority migration, or a permission grant. Existing local recovery agents should supply the actual template census and lineage. Validate destinations and accepted policies before implementation.

JSON syntax and basic design consistency were checked during packaging. That does not qualify the proposed evaluator or any measurement procedure. The main document provides evidence/source boundaries, source references, and the implementation acceptance test.
