# Product Evaluation Protocol — preliminary v0.2

Immediate handoff: **START-HERE-AGENT.md**.

The main specification retains the v0.1 evaluation model and adds autonomous mission/assignment derivation, grader qualification, execution epochs, restartable work, and a file-first bootstrap that does not wait for AgilePlus or Tracera. All roles may be agents operating under actual existing authority.

Files:

- `PRODUCT-EVALUATION-PROTOCOL-v0.2.md`: integrated specification; section 0 summarizes changes and sections 19–27 contain the additions.
- `START-HERE-AGENT.md`: portable session instructions for existing harnesses.
- `bootstrap-assignment.template.yaml`: blank record template; not a valid filled assignment, result, or authority grant.
- `protocol.contract.json`: updated machine-readable design contract; **not JSON Schema or an implemented validator**.
- `criterion-examples-v0.1-retained.json`: the prior three illustrative criterion designs, retained unchanged in meaning; not qualified executable adapters or actual findings.
- `MANIFEST.json`: digests of package contents; integrity inventory, not a trusted signature.

No live repos or devices were changed or re-audited while preparing v0.2. No historical thousand-criterion census was recovered in this revision. No actual performance, convergence, or economic advantage was measured. The no-platform workflow and its qualification cases still need execution in the user's local environment.

Design claims and external sources are distinguished in the main document. Prior source inspections remain identified as v0.1 history. This package is not a production engine, accepted governance migration, or regulatory certification.
