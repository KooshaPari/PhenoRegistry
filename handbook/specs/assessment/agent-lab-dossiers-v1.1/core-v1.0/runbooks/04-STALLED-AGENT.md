# Diagnose a stalled agent

Freeze and preserve the last accepted baseline and current useful candidate, including dirty work. Stop duplicative retries while retaining unrelated progress. Reproduce the failure using the referenced command/fixture at the actual revision. Check environment readiness before interpreting product behavior.

Compare at least the material alternatives: implementation defect; inconsistent assignment; invalid oracle; unavailable environment/permission; repeated ineffective strategy; cross-repo integration defect; mistaken intent/value premise. Write the smallest observation that separates the leading explanations.

Choose replay for reproduction, restart for corrupted/session-overloaded context, reseed for a different strategy/model/tool path, replan for a new decomposition, or amendment for a changed target. A change of session is not by itself a new method. Preserve negative knowledge and cumulative cost across all attempts. Use local mandate thresholds, not an arbitrary infinite retry budget.

Complete by recording the failure fingerprint, attempted hypotheses, reason for the chosen action, relevant source/evaluator/environment revisions, remaining resources and exact next step. Escalate only an actual reserved decision or absent authority; low confidence alone usually calls for evidence, not a human bottleneck.
