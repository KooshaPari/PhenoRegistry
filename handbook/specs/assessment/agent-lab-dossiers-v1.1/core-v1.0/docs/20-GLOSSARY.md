# Glossary

**Agent experience (AX):** discoverability, machine-readable interfaces, bounded effects, reset/replay, cancellation, parallelism and session continuity for agent consumers. Accessibility is tracked separately.

**Assignment:** a bounded statement of intended outcome, obligations, measurement bindings, authority and resource limits, frozen for an epoch.

**Audit:** evidence collection and assessment against a selected scope. It does not inherently authorize repair or publication.

**Canonical:** designated authoritative owner and correction procedure; not a guarantee every stored claim is true.

**Criterion:** reusable meaningful predicate. **Instance:** that predicate applied to a concrete subject scope. **Obligation key:** logical identity preventing aliases from receiving duplicate credit.

**Evidence:** an observation or artifact supporting a bounded claim. A link alone does not establish the relationship. **Provenance:** where the observation or artifact came from. Provenance does not prove the claim is correct.

**Epoch:** execution interval with materially fixed acceptance meaning. **Amendment:** an attributable change to that baseline.

**Finding:** a supported or unresolved issue requiring the correct next-action type. **Opportunity:** a possible improvement, not automatically accepted debt.

**Gate:** conjunction of mandatory conditions that unrelated points cannot compensate for. **Scorecard:** a generated view, not the underlying state store.

**Qualification:** evidence that a specified instrument accepts valid and rejects meaningful invalid cases within a declared scope.

**Verification:** assessment against requirements. **Validation:** assessment of whether the intended mission or beneficiary need is met [NASA-IVV].

**Restart:** new worker context. **Replay:** reproduce conditions. **Reseed:** vary approach/model/tool. **Replan:** alter search strategy. **Contract revision:** change target in a new epoch.

**Outbox:** pending delivery intent. **Receipt:** actual destination acceptance evidence. **S/R/L:** evaluated subject, report-storage revision and registry receipt/revision.

**Slice MVP:** a bounded beneficiary can obtain a minimum promised outcome through a complete required journey, with mandatory safeguards and feedback. It is not automatically external value validation.

**Final handoff:** a consolidated release of this package. It does not mean every underlying portfolio product is finished or every criterion has been executed.
