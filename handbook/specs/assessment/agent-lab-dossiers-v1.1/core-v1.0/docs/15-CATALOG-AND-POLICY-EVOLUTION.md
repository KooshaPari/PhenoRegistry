# Evolving the institution without moving the goalposts

## Stable IDs

Do not reuse an old criterion ID for a different predicate. A wording-only clarification can retain meaning with a new revision; a changed obligation needs a reviewed migration. Preserve source crosswalks, prior versions, rejected alternatives and impacted consumers. Deleting an obsolete criterion from active scope does not erase historical results.

## Compare epochs

Classify each change as product, evidence, scope, evaluator, policy or intent. When practical, measure the same preserved subject under both baselines to isolate measurement movement. Keep the old report. A new catalog cannot silently become the grader for an old assessment. The reference kernel intentionally requires the shipped catalog digest; replay using the matching preserved release or a qualified migration path.

## Anti-inflation

Adding aliases or splitting a predicate must not increase its weight. Maintain a logical obligation key and, in richer reducers, a fixed budget per obligation group. Platform instances can have deliberate independent weights when their risk is genuinely separate, but must not be presented as newly discovered conceptual criteria. Investigate repeated easy point gains with unchanged core-journey results.

## Change control proportionality

A low-risk clarifying note can use a small record. Changing release security acceptance, custody rules or authority requires stronger qualification and actual mandate. Agents can own both operations and amendments; they cannot bypass the trust root by writing a new policy file. New urgent evidence can suspend an affected gate while the next baseline is prepared.

## Institutional correction

When the evaluator is wrong, preserve the error, invalidate affected claims, identify decisions made from them, qualify the fix and replay relevant baselines. When the mission is wrong, preserve what was learned and compare narrow, pivot, merge, pause and no-action alternatives. Canonical records must enable correction, not defend the institution's previous answer.
