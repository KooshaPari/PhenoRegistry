# Metrics and reporting contract

A scorecard is a generated view over evidence, not the source of truth. Every report carries subject, assignment epoch, catalog, evaluator, observation window, inspected scope and limitations.

## Required views

Inventory: declared, implemented and observed capabilities with source and collection scope. Assurance: applicability, P/F/U, execution blockers, freshness, qualification and non-compensating gates. Maturity: beneficiary slice, readiness vector and value evidence. Discovery: planned and unplanned obligations, opportunities and research gaps. Work: accepted versus proposed backlog, true dependency path and wakeup conditions. Lifecycle: alternatives, decision authority, evidence and reversal conditions.

## Progress metrics

Report net verified gate closure inside an epoch, reopened obligations, age of required evidence, time to first valid outcome, time to qualification, time to consumer learning, recurring failure signatures, blocked critical-path time, cost per accepted outcome and useful disconfirmation. For stochastic tools report per-request reliability and best-of-attempt success separately. Retain censored and failed work.

## Trust metrics

Measure seeded-fault detection, valid-witness acceptance, instrument false positives/negatives on labeled fixtures, semantic disagreement, stale-evidence reuse violations, duplicate/conflicting events, missing provenance and unauthorized effect attempts. High code coverage is not a substitute for these signals. Fixture performance is limited to the fixture distribution.

## Do not report

Do not report a universal percent finished for an open-world evolving product. Do not average unlike product stages into one letter grade as strategic truth. Do not treat commit count, generated documentation, agent count or catalog size as value. Do not treat a missing credential as a product failure or a local file write as remote publication.

## Decision dashboard

A useful summary states: the scoped outcome; what currently works; required failures; what is unknown and why; real value evidence; the next discriminating action; remaining resources; and the conditions for promotion, pause or revision. Include counterevidence and zero-action alternatives when they matter. Renderers may be replaced without changing accepted records.
