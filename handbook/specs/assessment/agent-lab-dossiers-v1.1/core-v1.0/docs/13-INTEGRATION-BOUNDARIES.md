# Integration boundaries

This release defines portable contracts and adapters to qualify; it does not invent live API endpoints or claim to have called unavailable services. Consult actual current installed interfaces before implementing a write path.

| Owner or tool | Integration role | Boundary |
|---|---|---|
| Subject owner | Intent, assignments, results, findings and evidence references | Owns product truth, not unrelated portfolio state |
| AgilePlus | Work-package lifecycle, claims and governance orchestration | Tool implementation is not a portfolio registry |
| Tracera | Trace links, evidence graph, impact and coverage projection | Optional to bootstrap, no duplicate authority |
| Benchora / accepted evaluator owner | Qualified check adapters and measurement method | Not strategic investment authority |
| RepoLedger / accepted registry instance | Identity, disposition and assessment references | Does not duplicate all raw evidence |
| ResearchLedger | Source provenance and research decisions | Does not auto-accept product scope |
| SessionLedger | Actual runs and continuation pointers | Session narrative alone is not product proof |
| PhenoDocs | Versioned readable projections | No authority promotion from rendered Markdown |
| Accepted portfolio owner, including AGSLAG only if adopted | Mandates and resource/disposition decisions | No inferred deployment or permission grant |

## Adapter contract

Resolve actual version/capabilities, authentication scope, supported record fields, idempotency and conflict semantics, error categories, read-after-write verification, receipt identity, privacy rules, retry budget, fallback and compatibility. Record one successful and one negative-control receipt for each required path. A named dependency is not adoption.

## Mapping

Work items map to real AgilePlus work objects when available, preserving source IDs and lifecycle differences. Evidence and claim relations map to Tracera without collapsing observation, interpretation and acceptance. Registry writes store pointers/digests and actual disposition decisions, not another manually maintained truth copy. Research imports retain rights and source versions. Session records link attempts to outcome evidence.

## No-platform acceptance

Disable the optional transport. The local loop must still create a correctly scoped assignment, run a check, produce findings and checkpoint. Registration remains PENDING or BLOCKED, never REGISTERED. Re-enable the qualified adapter and reconcile idempotently without re-running product effects. An authority failure remains localized to the unavailable effect.

## Migration

Before moving existing records, determine canonical owner, consumers, sensitive content, history and unique artifacts. Build reversible crosswalks, test the consumer, then cut over under actual authority. Do not create new registry pollution in AgilePlus or PhenoDocs while cleaning older pollution elsewhere.
