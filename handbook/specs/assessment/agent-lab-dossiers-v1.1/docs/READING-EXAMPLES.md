# How to read the examples

## The executed pair

Open `examples/01-restoration-before/ASSESSMENT.html` and `examples/02-restoration-after/ASSESSMENT.html`. Both use the same two accepted outcome predicates. Inspect `raw/observations.json` and `raw/qualification.json`. The first implementation says success but leaves the target empty and fails to reject a corrupted backup. The second restores the required records and rejects corruption.

This is an actual local fixture execution. It is not an agent autonomously designing a production system, a regression assessment of the user's code, or proof of general restoration correctness.

## The six hypothetical dossiers

These illustrate richer decisions and states without inventing a real audit. A visible scenario PASS means “assume this fact for the example.” It does not mean the tool executed that check. All results stay PROPOSED, there are no qualification records, and evidence-based acceptance remains blocked.

That is intentional: copying an example into a repository must not manufacture evidence. An agent turning one into a real dossier must resolve the subject, authority and scope and collect new actual observations.

## What each case teaches

**ParcelKit:** agent-created intent is legitimate, but a separate repository still needs consumers, alternatives, and a reversal trigger. Missing external value evidence is not automatically proof of worthlessness. Its pure-library keyboard exclusion is capability-specific, not a blanket exemption for all CLIs.

**Draftboard:** 36 selected criteria cover all 18 executive domains, not every criterion in those domains. Visual consistency coexists with failed durable behavior and keyboard access. A generic “looks complete” judgment would miss the most important defects.

**HarborAPI:** local, hosted and operational readiness are distinct. Missing authority blocks hosted verification, not all useful work. Unresolved tenancy is an applicability problem that must not vanish from a percentage. Its outbox entry has zero attempts and no receipt.

**RelaySuite:** independent component success cannot establish a composed consumer journey. The pinned producer/consumer contract matters more than the average of local grades. An owner must be accountable for the boundary failure.

**PathJudge before/after:** the same fictional subject descriptor is used in both snapshots. The assignment and grading interpretation change. The delta is an evaluator correction, not product improvement. An actual use would require a qualified revised instrument and new evidence.

## A filled semantic review is not an unsupported adjective

Each dossier contains a topic, assessment, supporting case, contrary case, discriminating experiment, and confidence basis. This lets a replacement agent challenge the interpretation without inheriting the previous agent's narrative as fact. It does not require private chain-of-thought disclosure or pretend that agreement between agents is independent evidence.
